# 챔피언 스탯 설명서

챔피언 숫자는 `shared/champions/<챔피언>.js`에 있다. 이 문서만 보고 숫자를 조정할 수 있도록 각 항목의 뜻·단위·공식을 정리한다.

- 거리 단위: 월드 좌표 1 = LoL 1유닛
- 시간 단위: 초
- 숫자를 바꾼 뒤에는 루트에서 `npm run check`를 실행해 통과를 확인한다.
- 게임 화면 왼쪽 위 디버그 정보(이동속도, 허수아비 체력 등)로 결과를 바로 볼 수 있다.

---

## 크기

| 항목 | 뜻 | 기준값 |
|---|---|---|
| `gameplayRadius` | 판정용 반경(히트박스). 평타 사거리, 투사체 적중에 쓰인다. 화면의 옅은 테두리 원 | LoL 대부분 55~80, 중간값 65 |
| `pathingRadius` | 이동 충돌 반경. 벽·다른 캐릭터와 이 크기로 부딪힌다. 화면의 진한 원(몸) | `gameplayRadius`보다 작거나 같아야 함 |

## 기본 능력치

| 항목 | 뜻 | 단위 | 기준값 |
|---|---|---|---|
| `maxHp` | 최대 체력 | | |
| `maxMana` | 최대 마나 | | 마나를 쓰지 않는 챔피언은 0 |
| `moveSpeed` | 기본 이동속도 (아래 공식의 B) | 유닛/초 | LoL 325~355 |

### 이동속도 공식

```
V_raw = (B + F) × (1 + ΣP) × Π(1 + M_i) × (1 − S × (1 − R))
```

- B: 기본 이동속도(`moveSpeed`)
- F: 고정 증가량의 합
- ΣP: 퍼센트 증가량의 합
- M_i: 곱연산 증가량
- S: 둔화 비율. 가장 강한 둔화 하나만 적용
- R: 둔화 저항

이후 상한·하한 보정을 적용한다.

| V_raw | 최종 속도 |
|---|---|
| 490 초과 | V_raw × 0.5 + 230 |
| 415 초과 ~ 490 | V_raw × 0.8 + 83 |
| 220 ~ 415 | 그대로 |
| 0 이상 ~ 220 미만 | 110 + V_raw × 0.5 |
| 0 미만 | 110 + V_raw × 0.01 |

## 기본 공격 (`attack`)

| 항목 | 뜻 | 단위 | 비고 |
|---|---|---|---|
| `range` | 공격 사거리 (A) | 유닛 | 원거리 보통 500~650, 근접 125~175 |
| `damage` | 1회 데미지 | | |
| `attackSpeed` | 초당 공격 횟수 | 회/초 | 0.625면 1.6초에 한 번 |
| `windupRatio` | 공격 주기 중 발사 전 준비 동작 비율 | 0~1 | 0.2 × 1.6초 = 0.32초 후 발사. 이 시간 안에 이동 명령을 내리면 공격이 취소됨 |
| `projectileSpeed` | 평타 투사체 속도 | 유닛/초 | 대상을 따라가는 유도형 |
| `projectileRadius` | 평타 투사체 크기 | 유닛 | 적중 판정과 그림 크기 |

### 평타 사거리 판정

```
d ≤ A + r1 + r2
```

- d: 두 캐릭터 중심 사이 거리
- A: `range`
- r1, r2: 공격자와 대상의 `gameplayRadius`
