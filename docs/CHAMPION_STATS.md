# 챔피언 스탯 설명서

챔피언 숫자는 `shared/champions/<챔피언>.js`에 있다. 이 문서만 보고 숫자를 조정할 수 있도록 각 항목의 뜻·단위·공식을 정리한다.

- 거리 단위: 월드 좌표 1 = LoL 1유닛
- 시간 단위: 초
- 숫자를 바꾼 뒤에는 루트에서 `npm run check`를 실행해 통과를 확인한다.
- 게임 화면 왼쪽 위 디버그 정보(이동속도, 허수아비 체력 등)로 결과를 바로 볼 수 있다.

## 크기

| 항목 | 뜻 | 기준값 |
|---|---|---|
| `gameplayRadius` | 판정용 반경(히트박스). 평타 사거리, 투사체 적중에 쓰인다. 화면에 보이는 캐릭터 원 | LoL 대부분 55~80, 중간값 65 |
| `pathingRadius` | 이동 충돌 반경. 벽·다른 캐릭터와 이 크기로 부딪힌다. 화면에는 보이지 않음 | `gameplayRadius`보다 작거나 같아야 함 |
| `selectionRadius` | 클릭 선택 반경. 마우스로 이 캐릭터를 고를 수 있는 범위. 크기 변화 효과에 영향받지 않음 | 게임플레이 반경보다 넉넉하게 |

| 항목 | 뜻 | 단위 | 기준값 |
|---|---|---|---|
| `maxHp` | 최대 체력 | | |
| `maxMana` | 최대 마나 | | 마나를 쓰지 않는 챔피언은 0 |

### 이동속도 공식

```
V_raw = (B + F) × (1 + ΣP) × Π(1 + M_i) × (1 − S × (1 − R))
```

- B: 기본 이동속도(`moveSpeed`)
- F: 고정 증가량의 합
- ΣP: 퍼센트 증가량의 합
- M_i: 곱연산 증가량
- S: 둔화 비율. 가장 강한 둔화 하나만 적용
- R: 둔화 저항

이후 상한·하한 보정을 적용한다.

| V_raw | 최종 속도 |
|---|---|
| 490 초과 | V_raw × 0.5 + 230 |
| 415 초과 ~ 490 | V_raw × 0.8 + 83 |
| 220 ~ 415 | 그대로 |
| 0 이상 ~ 220 미만 | 110 + V_raw × 0.5 |
| 0 미만 | 110 + V_raw × 0.01 |

## 기본 공격 (`attack`)

| 항목 | 뜻 | 단위 | 비고 |
|---|---|---|---|
| `type` | `'ranged'`(원거리) 또는 `'melee'`(근접) | | 선택. 적지 않으면 `'ranged'` |
| `range` | 공격 사거리 (A) | 유닛 | 원거리 보통 500~650, 근접 125~175 |
| `damage` | 공격력(AD). 평타는 공격력 100% 물리 피해 | | |
| `attackSpeed` | 기본 공격속도 (b) | 회/초 | 0.625면 1.6초에 한 번 |
| `attackSpeedRatio` | 공격속도 계수 (m) | | 선택. 적지 않으면 `attackSpeed`와 같은 값 |
| `windupRatio` | 선딜레이 비율 (p) | 0~1 | LoL 대부분 0.15~0.3 |
| `windupModifier` | 선딜레이 보정값 (k) | | 선택. 적지 않으면 1 |
| `projectileSpeed` | 평타 투사체 속도 | 유닛/초 | 원거리만 필요. 대상을 따라가는 유도형 |
| `projectileRadius` | 평타 투사체 크기 | 유닛 | 원거리만 필요. 적중 판정과 그림 크기 |

### 평타 사거리 판정

```
d ≤ A + r1 + r2
```

- d: 두 캐릭터 중심 사이 거리
- A: `range`
- r1, r2: 공격자와 대상의 `gameplayRadius`

### 평타 데미지

```
피해 = 공격력 × (치명타면 critDamage) × 방어력 배율
방어력 배율 = 100 / (100 + 방어력)          (방어력 ≥ 0)
            = 2 − 100 / (100 − 방어력)      (방어력 < 0)
```

- 치명타 여부는 발사 순간 정하고, 방어력은 맞는 순간 대상의 값으로 계산한다.
- 예: 공격력 60, 방어력 24 → 60 × 100/124 = 48.4. 치명타면 105 × 100/124 = 84.7.

### 공격 타이머

```
T = 1 / AS          (AS: 총 공격속도)

평타 시작
  ├── 선딜레이 W ──┤── 쿨다운 (T − W) ──┤
  │ 멈춰 서 있음    │ 자유롭게 이동      │
  │ 이동하면 취소   │ 새 평타 시작 불가  │
  0               발사                T
```

- 우클릭 한 번이 "추적(chase) → 정지 → 선딜레이 → 발사 → 쿨다운 → 다시 공격"을 반복한다.
- 선딜레이 도중 이동하면 평타가 취소되고 타이머가 0으로 돌아간다 (손해 시간 없음).
  - 단, 선딜레이 마지막 1틱(1/30초)은 취소되지 않는다. 선딜레이가 1틱 이하로 짧으면 취소할 수 없다.
  - 대상이 "사거리 + 100"보다 멀어지거나, 죽거나, 타겟 불가가 되면 끊긴다.
- 발사 순간: 근접은 즉시 적중, 원거리는 투사체 생성.
- 발사 후에는 이동해도 불이익이 없다 (무빙 평타). 단, 발사 직후 1틱 동안의 명령은 다음 틱에 처리된다.

### 총 공격속도

```
AS = m × x + b      (x: 추가 공격속도의 합, 예: +50% → 0.5)
```

- `attackSpeedRatio`(m)를 적지 않으면 m = b → AS = b × (1 + x)
- 범위: 최소 0.2, 최대 3.003

### 선딜레이 시간

```
W = W0 + k × (T × p − W0)
W0 = p / b
```

- k = 1이면 W = T × p (공격속도가 오르면 선딜레이도 같은 비율로 짧아짐)
- k < 1이면 공격속도가 올라도 선딜레이가 덜 짧아짐

예: b = 0.625, p = 0.2 → T 1.6초, W 0.32초, 쿨다운 1.28초. 추가 공격속도 +100%면 T 0.8초, W 0.16초.

## 스킬 (`skills`)

`skills: { Q: {...}, W: {...}, E: {...}, R: {...} }` 형태. 레벨별 값은 `[1레벨, 2레벨, 3레벨, 4레벨, 5레벨]` 숫자 5개 배열.
스킬은 **조준(targeting) / 발동(activation) / 효과(effects)** 세 축으로 정의한다. 기준은 `docs/SKILL_DESIGN.md`.

### 공통 규칙
- 시전 조건: 살아 있음, 쿨타임 0, 마나 충분, 다른 스킬 시전 중 아님
- 시전하면 마나 소모와 쿨타임이 바로 시작되고, `activation.castTime` 동안 멈춰 선 뒤 효과가 발동한다.
- 시전하면 평타 선딜레이는 취소된다 (마지막 1틱 제외). 시전이 끝나면 하던 이동·평타 명령을 이어 간다.
- 스킬 피해는 치명타가 없다.

### 공통 항목

| 항목 | 뜻 | 단위 |
|---|---|---|
| `name` | 스킬 이름 | |
| `manaCost` | 마나 소모 | 레벨별 |
| `cooldown` | 재사용 대기시간 | 초, 레벨별 |

### 조준 `targeting`

| 항목 | 뜻 |
|---|---|
| `type` | 조준 방식. 지금 구현: `'direction'` (마우스 방향) |
| `range` | 사거리 (유닛). 방향 지정 투사체는 이 거리만큼 날아감 |
| `outOfRange` | 사거리 밖을 찍었을 때. 지금 구현: `'maxRange'` (최대 사거리로 시전) |

### 발동 `activation`

| 항목 | 뜻 |
|---|---|
| `type` | 발동 방식. 지금 구현: `'normal'` (누르면 한 번) |
| `castTime` | 시전 시간 (초). 30틱 단위로 올림되어 0.25초는 실제 0.267초 |

### 효과 `effects` (배열, 위에서부터 차례로 발동)

**투사체** `{ type: 'projectile', ... }`

| 항목 | 뜻 |
|---|---|
| `speed` | 속도 (유닛/초) |
| `radius` | 반지름 (폭 = 반지름 × 2). 적의 `gameplayRadius`와 닿으면 적중 |
| `collision` | `'first'`: 처음 맞은 적 하나만, `'pierce'`: 지나가는 적 모두 (각각 한 번) |
| `onHit` | 적중 시 효과 목록 (아래) |

**적중 시 효과** `onHit`

| type | 항목 | 뜻 |
|---|---|---|
| `damage` | `damageType` | 피해 종류. 지금 구현: `'physical'` |
| | `base` | 기본 피해 (레벨별) |
| | `adRatio` | 총 공격력 계수 |
| | `apRatio` | 주문력 계수 |
| `reduceCooldowns` | `amount` | 시전자의 모든 스킬 쿨타임 감소량 (초) |

```
피해 = (기본 피해 + 총 공격력 × adRatio + 주문력 × apRatio) × 방어력 배율
```

- 피해량은 발동 순간 시전자의 스탯으로 정하고, 방어력은 맞는 순간 대상의 값으로 계산한다.
- 예: Q 1레벨, 공격력 60, 주문력 0, 대상 방어력 24 → (20 + 78) × 100/124 = 79.0
