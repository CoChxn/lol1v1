# 챔피언 스탯 설명서

챔피언 숫자는 `shared/champions/<챔피언>.js`에 있다. 이 문서만 보고 숫자를 조정할 수 있도록 각 항목의 뜻·단위·공식을 정리한다.

- 거리 단위: 월드 좌표 1 = LoL 1유닛
- 시간 단위: 초
- 숫자를 바꾼 뒤에는 루트에서 `npm run check`를 실행해 통과를 확인한다.
- 게임 화면 왼쪽 위 디버그 정보(이동속도, 허수아비 체력 등)로 결과를 바로 볼 수 있다.

## 크기

| 항목 | 뜻 | 기준값 |
|---|---|---|
| `gameplayRadius` | 판정용 반경(히트박스). 평타 사거리, 투사체 적중에 쓰인다. 화면에 보이는 캐릭터 원 | LoL 대부분 55~80, 중간값 65 |
| `pathingRadius` | 이동 충돌 반경. 벽·다른 캐릭터와 이 크기로 부딪힌다. 화면에는 보이지 않음 | `gameplayRadius`보다 작거나 같아야 함 |
| `selectionRadius` | 클릭 선택 반경. 마우스로 이 캐릭터를 고를 수 있는 범위. 크기 변화 효과에 영향받지 않음 | 게임플레이 반경보다 넉넉하게 |

### 이동속도 공식

```
V_raw = (B + F) × (1 + ΣP) × Π(1 + M_i) × (1 − S × (1 − R))
```

- B: 기본 이동속도(`moveSpeed`)
- F: 고정 증가량의 합
- ΣP: 퍼센트 증가량의 합
- M_i: 곱연산 증가량
- S: 둔화 비율. 가장 강한 둔화 하나만 적용
- R: 둔화 저항

이후 상한·하한 보정을 적용한다.

| V_raw | 최종 속도 |
|---|---|
| 490 초과 | V_raw × 0.5 + 230 |
| 415 초과 ~ 490 | V_raw × 0.8 + 83 |
| 220 ~ 415 | 그대로 |
| 0 이상 ~ 220 미만 | 110 + V_raw × 0.5 |
| 0 미만 | 110 + V_raw × 0.01 |

## 기본 공격 (`attack`)

| 항목 | 뜻 | 단위 | 비고 |
|---|---|---|---|
| `type` | `'ranged'`(원거리) 또는 `'melee'`(근접) | | 선택. 적지 않으면 `'ranged'` |
| `range` | 공격 사거리 (A) | 유닛 | 원거리 보통 500~650, 근접 125~175 |
| `damage` | 기본 공격력(AD). 평타는 총 공격력 100% 물리 피해. 추가 공격력 = 총 공격력 − 이 값 | | |
| `attackSpeed` | 기본 공격속도 (b) | 회/초 | 0.625면 1.6초에 한 번 |
| `attackSpeedRatio` | 공격속도 계수 (m) | | 선택. 적지 않으면 `attackSpeed`와 같은 값 |
| `windupRatio` | 선딜레이 비율 (p) | 0~1 | LoL 대부분 0.15~0.3 |
| `windupModifier` | 선딜레이 보정값 (k) | | 선택. 적지 않으면 1 |
| `projectileSpeed` | 평타 투사체 속도 | 유닛/초 | 원거리만 필요. 대상을 따라가는 유도형 |
| `projectileRadius` | 평타 투사체 크기 | 유닛 | 원거리만 필요. 적중 판정과 그림 크기 |

### 평타 사거리 판정

```
d ≤ A + r1 + r2
```

- d: 두 캐릭터 중심 사이 거리
- A: `range`
- r1, r2: 공격자와 대상의 `gameplayRadius`

### 평타 데미지

```
피해 = 공격력 × (치명타면 critDamage) × 방어력 배율
방어력 배율 = 100 / (100 + 방어력)          (방어력 ≥ 0)
            = 2 − 100 / (100 − 방어력)      (방어력 < 0)
```

- 치명타 여부는 발사 순간 정하고, 방어력은 맞는 순간 대상의 값으로 계산한다.
- 예: 공격력 60, 방어력 24 → 60 × 100/124 = 48.4. 치명타면 105 × 100/124 = 84.7.

### 공격 타이머

```
T = 1 / AS          (AS: 총 공격속도)

평타 시작
  ├── 선딜레이 W ──┤── 쿨다운 (T − W) ──┤
  │ 멈춰 서 있음    │ 자유롭게 이동      │
  │ 이동하면 취소   │ 새 평타 시작 불가  │
  0               발사                T
```

- 우클릭 한 번이 "추적(chase) → 정지 → 선딜레이 → 발사 → 쿨다운 → 다시 공격"을 반복한다.
- 선딜레이 도중 이동하면 평타가 취소되고 타이머가 0으로 돌아간다 (손해 시간 없음).
  - 단, 선딜레이 마지막 1틱(1/30초)은 취소되지 않는다. 선딜레이가 1틱 이하로 짧으면 취소할 수 없다.
  - 대상이 "사거리 + 100"보다 멀어지거나, 죽거나, 타겟 불가가 되면 끊긴다.
- 발사 순간: 근접은 즉시 적중, 원거리는 투사체 생성.
- 발사 후에는 이동해도 불이익이 없다 (무빙 평타). 단, 발사 직후 1틱 동안의 명령은 다음 틱에 처리된다.

### 총 공격속도

```
AS = m × x + b      (x: 추가 공격속도의 합, 예: +50% → 0.5)
```

- `attackSpeedRatio`(m)를 적지 않으면 m = b → AS = b × (1 + x)
- 범위: 최소 0.2, 최대 3.003

### 선딜레이 시간

```
W = W0 + k × (T × p − W0)
W0 = p / b
```

- k = 1이면 W = T × p (공격속도가 오르면 선딜레이도 같은 비율로 짧아짐)
- k < 1이면 공격속도가 올라도 선딜레이가 덜 짧아짐

예: b = 0.625, p = 0.2 → T 1.6초, W 0.32초, 쿨다운 1.28초. 추가 공격속도 +100%면 T 0.8초, W 0.16초.

## 스킬 (`skills`)

`skills: { Q: {...}, W: {...}, E: {...}, R: {...} }` 형태. 레벨별 값은 Q·W·E는 `[1레벨, …, 5레벨]` 숫자 5개, **궁극기 R은 숫자 3개** 배열.
스킬은 **조준(targeting) / 발동(activation) / 효과(effects)** 세 축으로 정의한다. 기준은 `docs/SKILL_DESIGN.md`.

### 공통 규칙
- 시전 조건: 살아 있음, 쿨타임 0, 마나 충분, 다른 스킬 시전 중 아님
- 시전하면 마나 소모와 쿨타임이 바로 시작되고, `activation.castTime` 동안 멈춰 선 뒤 효과가 발동한다.
- 시전하면 평타 선딜레이는 취소된다 (마지막 1틱 제외). 시전이 끝나면 하던 이동·평타 명령을 이어 간다.
- 스킬 피해는 치명타가 없다.

### 공통 항목

| 항목 | 뜻 | 단위 |
|---|---|---|
| `name` | 스킬 이름 | |
| `queueTime` | 쿨타임 선입력 허용 시간. 쿨타임이 이만큼 이하로 남았을 때 누르면 저장했다가 끝나는 순간 시전 (선택, 기본 0) | 초 |
| `manaCost` | 마나 소모 | 레벨별 |
| `cooldown` | 재사용 대기시간 | 초, 레벨별 |

### 조준 `targeting`

| 항목 | 뜻 |
|---|---|
| `type` | 조준 방식. 지금 구현: `'direction'` (마우스 방향), `'location'` (땅 클릭 위치) |
| `range` | 사거리 (유닛). 방향 지정 투사체는 이 거리만큼 날아감. 위치 지정은 이 거리 안의 지점 |
| `outOfRange` | 사거리 밖을 찍었을 때. 지금 구현: `'maxRange'` (최대 사거리로 시전. 위치 지정이면 그 방향으로 최대 사거리 지점) |

### 발동 `activation`

| 항목 | 뜻 |
|---|---|
| `type` | 발동 방식. 지금 구현: `'normal'` (누르면 한 번) |
| `castTime` | 시전 시간 (초). 30틱 단위로 올림된다: 0.25초 → 8틱(0.267초), 1초 → 30틱(1.0초). 시전하는 동안 캐릭터 둘레에 원이 차오른다 |
| `castBuffer` | 시전 중 들어온 명령을 저장했다가 시전이 끝나면 실행할지. `'allow'`(기본) / `'deny'` |

### 효과 `effects` (배열, 위에서부터 차례로 발동)

**투사체** `{ type: 'projectile', ... }`

| 항목 | 뜻 |
|---|---|
| `speed` | 속도 (유닛/초) |
| `radius` | 반지름 (폭 = 반지름 × 2). 적의 `gameplayRadius`와 닿으면 적중 |
| `collision` | `'first'`: 처음 맞은 적 하나만, `'pierce'`: 지나가는 적 모두 (각각 한 번) |
| `targets` | 맞을 수 있는 대상 (선택, 기본 `'all'`). `'champions'`: 챔피언만 맞고 다른 유닛은 통과 |
| `shape` | 화면 색 (선택). 모양은 모두 판정과 같은 크기의 원. `'bolt'`(기본): 팀 색, `'orb'`: 노란색, `'wave'`: 흰빛 하늘색 |
| `origin` | 발사 위치 (선택). `'castEnd'`(기본): 시전 시간이 끝날 때의 시전자 위치, `'castStart'`: 시전을 시작한 위치 (시전 중 밀려도 그대로) |
| `onHit` | 적중 시 효과 목록 (아래) |

**순간이동** `{ type: 'blink' }` (위치 지정 스킬)
- 발동 순간 시전자 위치에서 조준 지점 쪽으로 최대 `targeting.range`만큼 즉시 이동한다. 시전 중 밀렸으면 그 위치 기준으로 다시 계산한다.
- 도착 지점이 벽 밖이면 가장 가까운 벽 안쪽, 다른 캐릭터와 몸이 겹치면 바로 바깥으로 밀어낸다.
- 가던 이동은 멈추고, 평타 명령은 유지한다.

**유도 투사체** `{ type: 'homingProjectile', ... }`

| 항목 | 뜻 |
|---|---|
| `speed` | 속도 (유닛/초) |
| `acquireRadius` | 대상을 찾는 범위. 시전자 위치(순간이동 뒤면 도착 위치) 기준, 대상 가장자리까지 거리 |
| `priority` | `'nearest'`: 가장 가까운 적 / `'markedFirst'`: 시전자의 표식이 붙은 적 중 가장 가까운 적 우선 |
| `onHit` | 적중 시 효과 목록 (아래). 대상의 판정 원에 닿으면 적중 |

- 범위 안에 적이 없으면 투사체가 나가지 않는다. 대상이 죽거나 타겟 불가가 되면 사라진다.

**적중 시 효과** `onHit`

| type | 항목 | 뜻 |
|---|---|---|
| `damage` | `damageType` | `'physical'` (방어력으로 감소) / `'magic'` (마법 저항력으로 감소) / `'true'` (고정, 감소 없음) |
| | `base` | 기본 피해 (레벨별) |
| | `nonChampionBase` | 챔피언이 아닌 대상(미니언·몬스터)에게 쓰는 기본 피해 (선택, 레벨별) |
| | `adRatio` | 총 공격력 계수 (선택, 기본 0) |
| | `bonusAdRatio` | 추가 공격력 계수 (선택, 기본 0) |
| | `apRatio` | 주문력 계수 (선택, 기본 0) |
| `reduceCooldowns` | `amount` | 시전자의 모든 스킬 쿨타임 감소량 (초) |
| `reveal` | `duration` | 대상의 시야를 밝히는 시간 (초). 시야 기능이 생기면 동작 (지금은 기록만) |
| `applyMark` | `duration` | 표식 지속시간 (초). 맞는 순간 피해는 없음 |
| | `onDetonate` | 표식이 터질 때 효과 목록 (아래) |

```
피해 = (기본 피해 + 총 공격력 × adRatio + 추가 공격력 × bonusAdRatio + 주문력 × apRatio) × 저항 배율
저항 배율 = 100 / (100 + 방어력 또는 마법 저항력)
```

**표식 (`applyMark`)**
- 표식이 붙은 대상을 **시전자의 평타나 다른 스킬**이 맞히면 터진다.
  - 다른 스킬로 맞히면 그 스킬 피해가 먼저 들어가고, 그다음 표식이 터진다.
- 같은 스킬로 다시 맞히면 터지지 않고 시간만 갱신된다.
- 터질 때 피해는 그 순간 시전자의 스킬 레벨과 스탯으로 계산한다.

| `onDetonate` type | 항목 | 뜻 |
|---|---|---|
| `damage` | (위 `damage`와 같음) | 터질 때 피해 |
| `restoreMana` | `base` | 시전자 마나 회복량 |
| | `plusTriggerCost` | true면 터뜨린 스킬의 마나 소모량을 더 회복 (평타로 터뜨리면 0) |

- 피해량은 발동 순간 시전자의 스탯으로 정하고, 방어력은 맞는 순간 대상의 값으로 계산한다.
- 예: Q 1레벨, 공격력 60, 주문력 0, 대상 방어력 24 → (20 + 78) × 100/124 = 79.0
- 예: W 표식 1레벨, 추가 공격력 0, 주문력 0, 대상 마법 저항력 33 → 80 × 100/133 = 60.2. Q로 터뜨리면 마나 60 + 28 회복
- 예: E 1레벨, 추가 공격력 0, 주문력 0, 대상 마법 저항력 33 → 80 × 100/133 = 60.2
- 예: R 1레벨, 추가 공격력 0, 주문력 0 → 챔피언(마법 저항력 33) 350 × 100/133 = 263.2, 미니언 150 × 100/133 = 112.8
