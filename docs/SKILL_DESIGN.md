# 스킬 설계 기준

스킬은 하나의 기준으로 나누지 않고 **세 가지 축을 조합**해서 정의한다.

1. **조준 방식**: 어디를 어떻게 지정하는가
2. **발동 방식**: 언제, 몇 번, 얼마나 오래 쓰는가
3. **효과 종류**: 맞으면 무슨 일이 일어나는가

플레이어가 키를 어떻게 눌러 시전하는지(**입력 방식**: 일반 / 빠른 / 표시기와 함께 빠른 시전, 자기 시전)는 4번에 따로 정리한다.

예: "방향 지정 + 일반 발동 + 투사체·속박"

> **작업 규칙:** 새 스킬을 만들 때 세 축 중 하나라도 애매하면 (사거리 밖 클릭 동작, 관통 여부, 시전 시간, 피해 종류 등) **구현 전에 사용자에게 물어본다.** 추측으로 정하지 않는다.

---

## 1. 조준 방식 (Targeting)

| 방식 | 입력 | 설명 |
|---|---|---|
| 자동 (auto) | 없음 | 조준 입력 없이 사거리 안의 대상이나 범위를 자동으로 고름. 자기 강화, 자신 중심 범위 공격 등 |
| 방향 (direction) | 마우스 방향 | 입력한 방향으로 나감. 지나가는 모든 유닛에 영향(관통) 또는 처음 맞은 유닛에만 영향(충돌) |
| 위치 (location) | 땅 클릭 | 사거리 안의 위치를 지정하고, 스킬의 중심이 그 위치가 됨. 길이가 정해지지 않은 돌진도 여기에 속함 |
| 대상 (unit) | 유닛 클릭 | 가장 기본적인 조준 방식. 유효한 대상(적/아군/자신)은 스킬마다 다름 |
| 벡터 (vector) | 위치 + 방향 | 효과가 시작될 위치를 먼저 고르고, 그다음 경로의 방향을 지정 |
| 근접 (proximity) | 없음 | 가까이 있는 대상에게 자동으로 영향 |
| 패시브 (passive) | 없음 | 발동 요소가 없음 |

- **조준 방식과 범위 표시기(인디케이터)는 서로 대응하지 않는다.** 화면에 보이는 모양과 내부 입력 방식은 따로 정한다.
- **사거리 밖을 클릭했을 때의 동작**은 스킬마다 정한다.
  - 대상까지 걸어가서 시전
  - 위치까지 걸어가서 시전
  - 최대 사거리로 시전
  - 시전하지 않음

## 2. 발동 방식 (Activation)

| 방식 | 설명 |
|---|---|
| 일반 (normal) | 누르면 한 번 시전. 대부분의 스킬 |
| 토글 (toggle) | 시전할 때마다 켜짐/꺼짐을 오감. 켜 둔 동안 주기적으로 효과 (예: 0.5초마다 주변 피해) |
| 재시전 (recast) | 같은 키로 두 번째·세 번째 효과. 지속시간 안에 재시전 가능, 시간이 끝나면 자동 재시전되는 경우도 있음 |
| 충전 (charge) | 발동하면 힘을 모으기 시작하고 재시전으로 발사. 오래 모을수록 강해짐 (예: 충전 시간에 따라 사거리 증가) |
| 정신 집중 (channel) | 일정 시간 시전 상태를 유지. 끊길 수 있음 |
| 탄약·충전 횟수 (ammo) | 사용 횟수를 쌓아 두고 하나씩 소모 |

**시전 시간 (cast time)**
- 시전 시간과 정신 집중이 둘 다 있으면 항상 시전 시간이 먼저 적용된다.
- 시전 시간이 끝나는 순간 **시전자가 있는 위치에서** 발사되는 스킬이 많다.
- 서버 틱(30Hz) 단위로 처리되므로 시전 시간 0.25초는 틱 반올림 때문에 실제로 조금 더 길어진다.
  - LoL은 약 0.264초
  - 이 게임은 8틱째에 발동해서 0.267초

## 3. 효과 종류 (Effects)

**스킬 효과 분류**
부착, 오라, 순간이동(blink), 버프, 정신 집중, 군중 제어, 돌진(dash), 디버프, 무적, 소환물(pet), 투사체, 시야, 주문 보호막, 은신, 연결(tether), 대상 지정 불가

**피해 관련**
- 피해 종류: 물리 / 마법 / 고정
- 효과 유형: 범위 효과, 지속 피해, 치유 감소, 회복, 피해 전환, 보호막

## 4. 입력(시전) 방식 (Cast input)

스킬 입력은 **시전 방식 3가지**와 **자기 시전 보조 기능**으로 나뉜다. 흔히 말하는 "스마트키"는 빠른 시전이다.
이 설정은 조준 방식(1번)과 별개로, 플레이어가 키를 어떻게 눌러 시전하는지에 대한 것이다.

| 방식 | 키를 누르면 | 시전 시점 | 범위 표시 |
|---|---|---|---|
| 일반 시전 (normal) | 범위 표시가 뜨고 대기 | 좌클릭으로 대상·위치를 찍을 때 | 보임 |
| 빠른 시전 (quick, 스마트키) | 바로 시전 | 키를 누르는 순간 (커서 위치를 대상으로) | 안 보임 |
| 표시기와 함께 빠른 시전 (quickIndicator) | 누르는 동안 범위 표시 | 키를 떼는 순간 (그때의 커서 위치) | 보임 |

- 일반 시전: 키를 누른 뒤 좌클릭으로 대상 유닛이나 위치를 지정한다.
- 빠른 시전: "키를 누를 때 사용(use on key-down)". 취소할 틈이 없다.
- 표시기와 함께 빠른 시전: "키를 뗄 때 사용(use on key-release)". 일반 시전처럼 시전 전에 취소할 수 있으면서, 대상을 고르려고 다른 키를 누를 필요가 없다.

**특수 스킬에서의 차이**

| 스킬 | 일반 시전 | 빠른 시전 | 표시기와 함께 빠른 시전 |
|---|---|---|---|
| 충전 | 한 번 눌러 시작, 다시 눌러 시전 | 누르고 있으면 충전, 떼면 시전 | 빠른 시전과 비슷 |
| 벡터 | 한 번 눌러 시작 위치, 마우스를 움직인 뒤 다시 눌러 방향 | 누른 채 끌어서 시작 위치와 방향 선택 | 빠른 시전과 비슷, 범위 표시가 보임 |

**항상 빠른 시전으로 나가는 스킬**
- 자기 자신, 자동, 근접 조준 스킬은 지정할 대상이 없으므로 설정과 상관없이 항상 빠른 시전이다.
- 그 밖에 설정으로 바꿀 수 없는 예외 스킬도 있다.

**자기 시전 (Self cast)**: 세 시전 방식의 확장 기능. 아군이나 자신에게 쓸 수 있는 스킬을 대상 없이 쓰면 자동으로 자신에게 시전한다.
- 일반 + 자기 시전: 대상 선택을 기다리다가 유효한 대상이 없으면 자신에게
- 빠른 + 자기 시전: 누르는 즉시 커서 아래를 확인하고, 유효한 대상이 없으면 자신에게
- 표시기 + 자기 시전: 범위 표시를 보여 주고, 키를 뗄 때 커서 아래를 확인해서 없으면 자신에게

**취소 방법**
- 일반 시전의 대상 선택: 이동(우클릭), 공격, 소환물 이동 명령, Esc로 취소한다.
- 표시기와 함께 빠른 시전: 키를 떼기 전에 같은 방법으로 취소할 수 있다.
- 빠른 시전: 누르는 순간 나가므로 취소할 수 없다.

## 데이터 형식

챔피언 파일(`shared/champions/<챔피언>.js`)의 `skills.<키>`에 세 축을 그대로 적는다. 항목 설명은 `docs/CHAMPION_STATS.md`.

```js
Q: {
  name: '비전 화살',
  manaCost: [28, 31, 34, 37, 40],
  cooldown: [5.5, 5.25, 5, 4.75, 4.5],
  targeting: { type: 'direction', range: 1150, outOfRange: 'maxRange' },   // 1. 조준
  activation: { type: 'normal', castTime: 0.25 },                           // 2. 발동
  effects: [                                                                 // 3. 효과
    {
      type: 'projectile', speed: 2000, radius: 30, collision: 'first',
      onHit: [
        { type: 'damage', damageType: 'physical', base: [20, 45, 70, 95, 120], adRatio: 1.3, apRatio: 0.4 },
        { type: 'reduceCooldowns', amount: 1.5 },
      ],
    },
  ],
}
```

- 새 조준·발동·효과 종류를 구현하면 `shared/skills.js`(로직), `shared/champions/validate.js`(검사 규칙), `docs/CHAMPION_STATS.md`(설명), 아래 구현 현황을 함께 고친다.

| 축 | 구현됨 | 아직 |
|---|---|---|
